# **App Name**: EvolvedRouteSim

## Core Features:

- Network Topology Creation: Enables users to interactively create network topologies by adding nodes and edges to a canvas.
- Link Failure Simulation: Allows users to simulate link failures in the created network and observe the impact on routing protocols.
- RIP Simulation: Simulates the Distance-Vector (RIP) routing protocol, visualizing routing table updates and the 'counting to infinity' problem.
- OSPF Simulation: Simulates the Link-State (OSPF) routing protocol, visualizing LSA flooding and Dijkstra's algorithm to find the shortest path.
- Simulation Speed Control: Provides a slider to adjust the speed of the routing simulation, allowing users to control the pace of visualization.
- Algorithm selection: Lets user select either RIP or OSPF.
- Algorithm Explanation Sections: Provides sections explaining the algorithm and what is happening, making it a learning tool.

## Style Guidelines:

- Background color: Dark gray (#1C1C2B) for a professional look.
- Primary color: Vibrant green (#91C499) to highlight key elements and paths.
- Accent color: Chartreuse/yellow (#CFD11A) for flashes and highlights during simulations.
- Body and headline font: 'Roboto', a grotesque-style sans-serif, for a modern, objective feel.
- Code font: 'Source Code Pro' for displaying code snippets and routing tables clearly.
- Use modern, clean icons for actions like 'Run,' 'Reset,' and network elements.
- Employ subtle animations for packet movements and route changes to enhance the simulation's clarity.
